AnimationsOptions

AnimationsOptions class

Durations and curves of the layer's animations. Same fields and defaults as flutter_map_marker_cluster's.

zoom animates clusters splitting and merging when the zoom level changes (Duration.zero turns it off), spiderfy the markers of a spiderfied cluster gliding out and back, fitBound the camera moving to a tapped cluster, centerMarker the camera centering a tapped marker. On Android, iOS and macOS the markers move with the map's own ease-in-out curve, so fadeInCurve, fadeOutCurve, clusterExpandCurve, clusterCollapseCurve and spiderifyCurve apply only on the platforms drawn with flutter_map (web, Windows, Linux).
