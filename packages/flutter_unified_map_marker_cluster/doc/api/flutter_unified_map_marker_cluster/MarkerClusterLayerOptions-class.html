MarkerClusterLayerOptions

MarkerClusterLayerOptions class

Options of MarkerClusterLayerWidget: the fields, types and defaults of flutter_map_marker_cluster 8.2's MarkerClusterLayerOptions, plus clusterIconKey and spiderLegs.

On Android, iOS and macOS the markers and clusters are native map markers: every widget (Marker.child, the builder's cluster widget) is rasterised into a bitmap, so it cannot react to gestures or animate by itself. The options that need a Flutter widget on the map behave as follows there:

  • onMarkerDoubleTap, onMarkerHoverEnter and onMarkerHoverExit are never called (native markers report single taps only);
  • markerChildBehavior true skips onMarkerTap and centerMarkerOnClick (as on flutter_map); the marker's own Marker.onTap is still called;
  • polygonOptions's pattern is drawn solid.

flutter_map_marker_cluster's popupOptions (flutter_map_marker_popup) is not available: show a popup from onMarkerTap with a MarkerLayer or a Flutter overlay instead.
