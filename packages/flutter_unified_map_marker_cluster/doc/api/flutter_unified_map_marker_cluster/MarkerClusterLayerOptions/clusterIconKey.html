clusterIconKey

clusterIconKey property

Object Function(List<Marker> markers)? clusterIconKey
final

Native maps only: key of the bitmap of a cluster widget, so equal keys share one rasterised bitmap. Defaults to the number of markers, which is right when builder depends only on the count; return a key that captures everything the cluster widget shows otherwise (e.g. (markers.length, colorOf(markers))). The theme, text style, text direction, brightness and text scale need not be in it: when they change, the map rasterises every icon again.
