MarkerClusterNode

MarkerClusterNode class

A cluster of the tree built by MarkerClusterLayerWidget, as handed to onClusterTap. Same API as flutter_map_marker_cluster's MarkerClusterNode.

zoom is the zoom level the cluster is shown at; children are the clusters of the next level and the markers that are no longer clustered there; markers lists every marker below it, direct children first.
