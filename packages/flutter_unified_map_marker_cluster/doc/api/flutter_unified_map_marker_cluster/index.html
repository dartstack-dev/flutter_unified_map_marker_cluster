flutter_unified_map_marker_cluster

flutter_unified_map_marker_cluster library

Marker clustering for flutter_unified_map with the API of flutter_map_marker_cluster.

Classes

AnimationsOptions
Durations and curves of the layer's animations. Same fields and defaults as flutter_map_marker_cluster's.
MarkerClusterLayerOptions
Options of MarkerClusterLayerWidget: the fields, types and defaults of flutter_map_marker_cluster 8.2's MarkerClusterLayerOptions, plus clusterIconKey and spiderLegs.
MarkerClusterLayerWidget
Clusters MarkerClusterLayerOptions.markers on a UnifiedMap, like flutter_map_marker_cluster's MarkerClusterLayerWidget (same options).
MarkerClusterNode
A cluster of the tree built by MarkerClusterLayerWidget, as handed to onClusterTap. Same API as flutter_map_marker_cluster's MarkerClusterNode.
MarkerNode
A single Marker in the cluster tree. It is a Marker itself, like flutter_map_marker_cluster's MarkerNode.
MarkerOrClusterNode
A node of the cluster tree: a MarkerNode or a MarkerClusterNode. Same role as flutter_map_marker_cluster's.
PolygonOptions
Style of the convex hull shown over a cluster's markers while the map zooms to it (MarkerClusterLayerOptions.showPolygon). Same fields as flutter_map_marker_cluster's. Native maps draw pattern solid.
SpiderLegOptions
Native maps only: style of the lines joining the markers of a spiderfied cluster to it, drawn once the markers arrived. flutter_map_marker_cluster draws no legs, so there are none on web, Windows and Linux.
